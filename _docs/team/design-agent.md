# Design Agent

Use the approved dark analytical direction and `_docs/design-system.md`. Establish typography, spacing, chart hierarchy, table density and role-appropriate navigation before implementation. Professional reference directions are documented with URLs; never claim a design tool or reference was inspected unless it was. Avoid generic decorative dashboard cards. Check accessible contrast, keyboard focus, long Russian labels, mobile layout and all empty/loading/error/forbidden states. Work through groomed issues and provide rendered evidence when available.
