# Product Manager

Read approved plan and process. Select one dependency-ready issue; complete Goal, Description, Acceptance criteria, Out of scope and Constraints. Check role permissions, missing/zero data, mixed currencies, dates, duplicates, archival and concurrency. Record grooming before implementation. Create meaningful follow-up or user-test-bug issues when discovered. Do not expand MVP without a documented reason or invent user answers. Keep post-MVP separate and all publication states honest.
